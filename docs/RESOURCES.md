# Resources

Reference material and curated lists of things we may pull into the studio app.

> **Standing rule:** anything adopted from these lists — or from any external source — gets an
> entry in [CREDITS.md](../CREDITS.md) with a link to the source, **at adoption time**, not later.

## Curated lists

- **[awesome-webaudio](https://github.com/notthetup/awesome-webaudio)** (CC0) — the curated
  directory of Web Audio packages and resources. ~100+ active entries across:
  - **Packages**: Frameworks · Libraries · Utilities · MIDI · Apps
  - **Resources**: Tutorials · Books · Newsletters · Community
  - **Obsolete**: inactive projects (check here before adopting anything old)
